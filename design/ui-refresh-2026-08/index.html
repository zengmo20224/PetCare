PetCare 用户端 · UI 统一化改版提案 V2

基于 2026-08 现行界面的多模态扫描（5 张 Tab 页实拍 + tokens.css / uni.scss / mixins.css 令牌审读），提炼一套更统一、更协调、更贴近小程序设计规范的界面方案。

本稿为纯静态设计 Demo：未接后端接口、数据为演示占位，不修改 frontend/miniapp/src 下任何在用界面，供讨论评估后再决定是否分阶段落地。

390 宽移动视口 14 屏全覆盖 单一线性图标集 微信小程序规范对齐 零代码侵入

0一页看懂：五个改版动作

不改品牌基因（青绿主色、彩色宫格、卡片信息流全部保留），只收敛"不统一"的部分。

  • 背景与中性色并轨：页面底色统一 #F7F7F7，文字统一纯灰阶（#1A1A1A→#B2B2B2）。现行代码里 uni.scss 的米白 #FAF8F3 + 墨绿系文字（#19322E/#71817D）与 reset.css 已生效的 #F7F7F7 双轨并存，提案全部并到灰阶轨，青绿退出中性色、只负责操作与选中。
  • 功能色一锤定音：成功绿三套（wot #34d19d / uni #2E7D32 / demo #07C160）→ 统一 #07C160；红两套（#D84D4D / 价红 #FA5151）→ 统一 #FA5151 兼价格色；警告 #FA9D3B、信息 #10AEFF 各归其位。
  • 页头减负：现行 5 个 Tab 中 4 页有大面积深绿营销 banner（黄字强调），首页却没有，模式不一。V2：仅首页保留品牌 Hero（收敛高度并并入门店信息），其余页面标题交还导航栏，进页即搜索/内容。
  • 悬浮层唯一：现行同时存在 3 种 FAB（首页 AI、商品页购物车、社区页发帖）。V2：全应用只保留社区发帖一个 FAB；购物车改为列表工具行胶囊入口（图标+角标），AI 改为首页内容流末尾的"AI 助手卡"。
  • 图标与圆角归一：全部功能图标使用同一套线性 SVG（1.7px 圆头），emoji 退出功能位、只留空状态；圆角统一为 卡 12px / 控件 10px / 筛选胶囊全圆（现行 16px 卡 + 混用胶囊）。卡片默认轻投影+1px 细边，替代现行大投影。
