## 0. TL;DR（决策摘要）

| 维度 | 结论 |
|---|---|
| 当前小程序版是否可上架 | ❌ **否**。三大硬阻断：微信登录未实现、微信支付未实现、域名/HTTPS/白名单未配。 |
| 当前小程序版可否在开发者工具预览 | ⚠️ 骨架可编译（`dist/build/mp-weixin` 存在），但任何登录动作都会 422，且默认连 `127.0.0.1:8080`。 |
| 真实瓶颈是什么 | **资质办理周期**（营业执照 + 小程序认证 + 商户号 ≈ 1 个月起），不是技术。 |
| 最小可上架范围 | "纯预约服务"（宠物服务预约 + 社区）。**商品零售模块会被审核卡死**（详见 §3.2）。 |
| 推荐策略 | **先 H5 上线（V1）→ 同步办资质 → 小程序作为 V2，且首版砍商品零售**。 |
| 工作量 | 小程序首版（含登录+无支付）≈ 2-3 周；含微信支付 ≈ 4-6 周。 |

| 平台判断工具 | ✅ | `platform.ts` `isWeixinMiniProgram()` |
| tabBar + 36 页面 | ✅ | 结构完整 |

### 1.2 三大硬阻断

| # | 问题 | 位置 | 影响 |
|---|---|---|---|
| **B1** | 微信登录是**永远抛异常的占位** | `DisabledWechatLoginProvider.java`（`login()` 必抛 `wechat_login_not_enabled`） | 小程序里无法登录，所有需要 token 的功能 422 |
| **B2** | 登录页只有"手机号+密码"，**无微信授权入口** | `pages/auth/login.vue` | 小程序用户体验不可接受；审核会驳回 |
| **B3** | 请求默认连 `http://127.0.0.1:8080` | `request.ts:10` | 小程序禁止 http + IP，运行时直接报"不在域名白名单" |

### 1.3 其他缺口

| # | 问题 | 影响 |
|---|---|---|
| G1 | 无微信支付（当前 `paymentMethod: 'OFFLINE_STORE'` 纯线下） | "商品零售"类目审核必驳 |
| G2 | `manifest.json` 的 `mp-weixin.appid` 为空 | 无法上传代码到微信 |
| G3 | H5 端 `.env.production` 硬编码内网 LAN IP | 小程序构建前必须改真实域名 |
| G4 | 无用户协议/隐私政策页面 | 审核必查项 |
| G5 | 无 `wx.requirePrivacyAuthorize` 隐私弹窗 | 微信 2023 起强制 |
| G6 | 无客服入口（`button open-type="contact"` 或电话） | "宠物服务"类目要求 |
| G7 | 小程序首包体积未评估（uni-app + wot-design-uni 易超 2MB） | 主包超 2MB 无法上传 |
| G8 | 微信登录未写测试（后端 Provider 接口已抽好，缺真实实现和单测） | 违反 AGENTS.md §5 |

## 2. 资质办理清单（真实瓶颈，必须先动）

> 以下是中国大陆小程序上架的硬性手续。**这些不是技术问题，但没办下来技术做再多也上不了。** 建议立即启动，与技术并行。

| 资质 | 用途 | 办理渠道 | 预计周期 | 费用 |
|---|---|---|---|---|
| **营业执照**（企业或个体工商户） | 小程序主体认证、商户号申请 | 当地市监局 / 网上办照 | 3-15 工作日 | 几十到几百元 |
| **小程序账号 + 认证** | 拿 appid、绑定主体 | mp.weixin.qq.com 注册 → 实名认证 | 认证 1-3 工作日 | 认证费 300 元/年 |
| **类目资质：宠物服务** | 服务预约类目 | 小程序后台选类目 + 上传营业执照 | 选完即生效 | 0 |
| **类目资质：宠物食品/零售**（若要保留商品） | 商品零售类目 | 营业执照 + 可能需**食品经营许可证** | 食证 15-30 工作日 | 视地区 |
| **微信支付商户号**（若要保留商品零售） | 小程序内支付 | 微信支付商户平台申请 → 进件 | 3-7 工作日 | 0（费率 0.6%） |
| **ICP 备案域名** | 后端 API 必须备案域名 + HTTPS | 阿里云/腾讯云买域名 → 提交备案 | **7-20 工作日**（最长环节） | 域名费 + 服务器 |
| **SSL 证书** | HTTPS 必备 | Let's Encrypt（免费）或商业证书 | 即时（Let's Encrypt） | 0-几百元 |

**关键路径**：域名备案 ≈ 营业执照 ≈ 商户号 → **总周期 3-6 周**。这期间技术可以并行做完所有改造。

## 3. 微信审核规则适配

### 3.1 强制要求（不满足直接驳回）

1. **必须提供微信登录**（B1/B2 必须解决）
2. **域名 HTTPS + 备案 + 预先加白名单**（B3 必须解决）
3. **用户协议 + 隐私政策页面**（G4）
4. **`wx.requirePrivacyAuthorize` 隐私授权弹窗**（G5）
5. **首包 ≤ 2MB**（G7）
6. **客服入口**（G6）

### 3.2 类目规则（决定能否保留商品模块）

| 业务 | 推荐类目 | 支付方式限制 |
|---|---|---|
| 宠物服务预约 | 工具 > 宠物 | **允许线下付款**（无需微信支付） |
| 商品零售（商品订单模块） | 商业服务 > 电商 / 宠物 > 宠物食品 | **强制微信支付**，禁止跳第三方 |
| 社区发帖 | 社区 > 社交 | UGC 需备案 + 内容审核（你已有敏感词，✅） |

**关键决策**：商品零售类目强制微信支付，会触发 AGENTS.md §4"订单金额必须服务端事务校验"的支付链路改造（金额、退款、回调验签、超卖）。**强烈建议小程序 V1 砍掉商品模块，只上预约 + 社区**，把商品留到 H5 或小程序 V2。

### 3.3 内容合规

- 社区 UGC：你已有敏感词过滤（✅），但需在小程序后台配置**内容安全检测**（`security.msgSecCheck`），否则可能被通报
- 隐私政策必须真实披露：收集手机号、openid、位置、相册（上传图片）的用途

## 5. 推荐策略与里程碑

### 5.1 强烈推荐：**H5 先行，小程序 V2**

理由：
1. H5 已完成度 ~85%，小程序是从零做登录和支付
2. H5 上线只需补 HTTPS + 安全漏洞 + 备份（之前评估的 P0/P1）
3. 资质办理期间技术不阻塞（H5 不需要小程序 appid）
4. 小程序首版砍商品零售，避开支付链路改造，把工作量从 4-6 周压到 2-3 周

### 5.2 里程碑（假设资质并行办理）

| 阶段 | 内容 | 周期 | 与资质的关系 |
|---|---|---|---|
| **M0（现在）** | H5 上线清单：提交 H1 幂等、修 H2 限流、HTTPS、备份、安全漏洞 | 1-2 周 | 不依赖任何资质 |
| **M1** | 申请营业执照 + 域名备案 + 小程序账号 | 3-6 周（并行进行） | 阻塞 M3 |
| **M2** | 后端：`RealWechatLoginProvider` + openid 账号体系 + `getPhoneNumber` | 1 周 | 需小程序 appid/secret（M1 产出） |
| **M3** | 前端：登录页改造 + 砍商品 + 隐私协议 + 体积优化 | 1 周 | 需 HTTPS 域名（M1 产出） |
| **M4** | 真机灰度 + 提交审核 + 修审核意见 | 1-2 周 | 需所有资质到位 |
| **M5（可选）** | 加微信支付，恢复商品模块（V2） | 2-3 周 | 需商户号 |

**关键路径总周期：M0 + M1（并行）+ M2 + M3 + M4 ≈ 5-7 周到上架。**

## 6. 风险清单

| 风险 | 等级 | 缓解 |
|---|---|---|
| **备案被驳回**（域名/主体问题） | 高 | 提前用云厂商代办；准备好主体证明 |

| **UGC 合规通报** | 中 | 接入 `msgSecCheck` + 人工审核机制 |
| ** AGENTS.md §4 订单金额事务**（若加支付） | 中 | 支付链路必须有直接测试，不能照抄 H5 |
